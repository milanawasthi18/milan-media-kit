# Milan Awasthi — Creator Media Kit

Open `index.html` in a browser to view the local webpage. Keep the `assets` folder and `milan-awasthi-media-kit.pdf` beside it; the page uses them for its artwork, inline videos, and PDF download button.

All three video previews on page 2 now play inline. Their MP4 files are in `assets/videos/` as `page-2-video-1.mp4`, `page-2-video-2.mp4`, and `page-2-video-3.mp4`. All three previews on page 3 play inline. Their MP4 files are in `assets/videos/page-3-video-1.mp4`, `assets/videos/page-3-video-2.mp4`, and `assets/videos/page-3-video-3.mp4`. The first page 3 preview crops the source video top and bottom to fit its widescreen frame. Other video previews remain part of the original page artwork.

To publish it online, upload the contents of this folder to a static website host. Include all files and folders so the artwork and videos load.
